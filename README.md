# GridPuzzle

Игра «Цветные пятнашки»

Игрок управляет выделенной клеткой на поле и должен переставить цветные блоки так, чтобы:
все синие квадраты оказались в синей колонке
все зелёные квадраты в зелёной колонке
все красные квадраты в красной колонке

По механике игра напоминает пятнашки:
можно двигать только соседние элементы
используется одна свободная клетка
цель, собрать правильную сортировку цветов

Блок может переместиться:
только в соседнюю пустую клетку
только по вертикали или горизонтали
диагональное движение запрещено
Чёрные клетки:
не двигаются
не могут быть заняты

Игрок побеждает, когда:
все синие блоки стоят в синей зоне
все зелёные блоки стоят в зелёной зоне
все красные блоки стоят в красной зоне

**КРАТКО ОБ ИГРЕ:**

Начало:
Создаётся сетка GridSize x GridSize (по умолчанию 3x3, максимум 9x9)
Каждая колонка получает свой уникальный цвет (красный, оранжевый, жёлтый...)
Плитки размещаются в случайном порядке, одна плитка (последняя) - пустая
Плитки перемешиваются 500 случайными ходами
Размер зазора между плиток, длина столбцов и строк настраивается в BP_GridController

Игровой процесс:
Игрок кликает по плитке
Если плитка находится рядом с пустой ячейкой - плитка физически перемещается в пустую ячейку и новые значения заносятся в массив
После каждого хода проверяется победа

Победа:
Победа наступает, когда каждая плитка находится в колонке своего цвета
Пустая ячейка должна быть там, где не хватает одной плитки
При победе показывается виджет, игра останавливается
Ввиджете можно перезапустить игру или выйти

Ключевые механизмы
Логика перемещения: плитка и пустая ячейка меняются местами в массиве, затем обновляют свои позиции
Анимация: плитка двигается к целевой позиции
Валидация ходов: проверяется, что клик по плитке, а не по пустоте, и что она соседняя с пустой

UI: курсор мыши всегда виден, клики обрабатываются через рейкаст

Цветовая схема (9 цветов)
Красный → Оранжевый → Жёлтый → Зелёный → Голубой → Синий → Фиолетовый → Тёмно-синий → Пурпурный
