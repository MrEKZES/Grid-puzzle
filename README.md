# GridPuzzle

Игра «Цветные пятнашки»

Игрок управляет выделенной клеткой на поле и должен переставить цветные блоки так, чтобы:
все синие квадраты оказались в синей колонке
все зелёные квадраты в зелёной колонке
все красные квадраты в красной колонке

По механике игра напоминает пятнашки:
можно двигать только соседние элементы
используется одна свободная клетка
цель, собрать правильную сортировку цветов

Блок может переместиться:
только в соседнюю пустую клетку
только по вертикали или горизонтали
диагональное движение запрещено
Чёрные клетки:
не двигаются
не могут быть заняты

Игрок побеждает, когда:
все синие блоки стоят в синей зоне
все зелёные блоки стоят в зелёной зоне
все красные блоки стоят в красной зоне

Developed with Unreal Engine 5
